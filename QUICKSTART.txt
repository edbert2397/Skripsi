🔧 USEFUL OPTIONS

   --model t5-base              Use smaller model (faster, 3-4GB VRAM)
   --rank 16                    Increase LoRA rank (default: 8)
   --lambda-orth 0.05           Change orthogonality weight (default: 0.1)
   --projection parameter       Use parameter-subspace (default: memory_gradient)
   --no-soft                    Disable soft constraint
   --no-hard                    Disable hard constraint
   --steps 2000                 More training steps
   --cpu                        Force CPU (very slow, testing only)

💡 VIBE CHECK (what to look for)

   ✅ Leakage plot drops to ~0.00 (projection working!)
   ✅ DLOG's R[1][0] ≈ R[0][0] (no forgetting on Task A)
   ✅ Baseline's R[1][0] << R[0][0] (severe forgetting)
   ✅ DLOG's FT < Baseline's FT (key thesis claim!)

🐛 TROUBLESHOOTING

   Problem: CUDA out of memory
   → python run_experiment.py --model t5-base

   Problem: Training stuck at 0%
   → First run downloads datasets (~500MB), wait 2-5 min

   Problem: ModuleNotFoundError
   → pip install -r requirements.txt
